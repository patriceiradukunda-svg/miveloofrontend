## Safety rules
- Do not delete existing pages during migration.
- Reuse existing routes when they already serve the intended purpose.
- Do not replace functional pages with placeholders.
- All unfinished pages must visibly say "Under Development".
- Never present mock data or untrained forecasts as real results.
- Enforce permissions on the server/backend, not only in navigation.
- Review authentication, legal, and API routes separately.
